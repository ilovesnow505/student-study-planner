# 📚 Student Study Planner & Assignment Tracker

A Python-based web application that helps students manage their subjects, assignments, due dates, priorities, and study progress.

The application is built using Streamlit, Python, and Pandas.

## ✨ Features

- Add new assignments
- View all assignments
- Track assignment due dates
- Set assignment priority
- Update assignment status
- Delete assignments
- Track completed assignments
- Track pending assignments
- View study progress dashboard
- Database storage

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- Git
- GitHub
- Visual Studio Code
